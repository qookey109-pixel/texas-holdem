## 重要限制

這不是 ChatGPT 所有聊天室的「完整逐字匯出」。

目前可使用的 File Library 搜尋介面可以找到附件、辨識內容與提供原始檔案卡片，
但不能把每個 File Library 原始檔的二進位內容直接複製到本地壓縮檔。因此：

1. 本包完整整理了目前能搜尋、辨識為德州撲克專案的附件清單。
2. 原始附件仍保存在 ChatGPT File Library，可從產生本包的聊天室檔案卡片開啟。
3. 圖片只在本包保存說明與識別資訊，沒有偽造或重新生成原圖。
4. GitHub Repository 本次讀取回傳 404，因此沒有把最新 Repository 原始碼壓縮進來。
5. 同名或歷史版本不會自行刪除，避免誤判與遺失。
