# 淘汰賽經濟 V1：第三輪候選決選

> 狀態：研究資料；本輪不修改正式盲注、補位籌碼、AI 決策或玩家籌碼。

## 目的

第二輪留下兩個候選：

- E1：候選 D 時鐘＋`full_table_target_bb = 160`＋blend 25%。
- E2：候選 D 時鐘＋`full_table_target_bb = 180`＋blend 25%。

第三輪不直接二選一，而是把目標深度與修正幅度放進小型網格，檢查 E1／E2 是否已經位於較穩定的位置。

## 模擬設定

- 盲注：候選 D，前段每 4 手、後段每 5 手，最高大盲 16,000。
- 種子：`20260805`～`20260809`，共 5 組。
- 每組種子、每種節奏：4,000 條。
- 節奏：快速、一般、慢速、爆發／拉鋸、前段僵局。
- 總路徑：100,000 條。
- 網格：`full_table_target_bb = 150～190`，每 5BB 一格；blend response = 15%、20%、25%、30%、35%。
- 所有候選使用完全相同的配對淘汰路徑。

這仍是合成壓力測試，不是正式玩家遙測；結果可用來比較公式穩定度，不能直接預測真實場次長度。

## 暫定接受門檻

門檻是 V1 研究用的設計篩選條件，不是經驗真理：

- 單挑桌面 BB：p5 至少 20.5、p95 不高於 190。
- 20～150BB 比率至少 84%。
- 低於 20BB 不高於 5%。
- 高於 200BB 不高於 4%。
- Gemini 進場中位數 48～55BB、p95 不高於 68BB。
- Gemini 撞 70BB 上限不高於 3%。
- 每 10 位補位角色，平均至少 3 位落在 min／max 之間。
- 累積補位深度 p95 不高於 475 entry-BB。
- 爆發／拉鋸路徑低於 20BB 不高於 20%。
- 前段僵局路徑高於 200BB 不高於 20%。

F1 沒有消除候選 D 時鐘本身的兩個極端尾端：

- 爆發／拉鋸仍可能在短時間內壓到短碼。
- 前段僵局仍可能在盲注封頂後留下偏深單挑。

但兩者都仍低於本輪暫定壓力門檻，不需要在 V1 再疊加玩家籌碼占比、角色進度升盲或硬額度系統。

## V1 模擬候選規格

```text
blind_clock = Candidate D
full_table_target_bb = 160
blend_response = 0.15

raw_entry_bb
= role_target_entry_bb
+ 0.15 × (
    full_table_target_bb
    - current_table_bb
    - role_target_entry_bb
  )

actual_entry_bb
= clamp(
    raw_entry_bb,
    role_min_entry_bb,
    role_max_entry_bb
  )
```

角色範圍仍沿用研究值：

| 階級 | min | target | max |
|---|---:|---:|---:|
| 中階 | 25BB | 35BB | 45BB |
| 高階 | 30BB | 40BB | 50BB |
| Gemini | 40BB | 50BB | 70BB |

## 結論

第三輪選定：

> **F1＝候選 D 純手數時鐘＋全桌目標 160BB＋15% blend response。**

這是目前的 **V1 實作候選**，不是已上線規格。正式遊戲仍未修改。

下一個工程步驟應是建立隔離的可玩試驗版：

1. 只在淘汰賽啟用 F1。
2. 保留正常模式原規則。
3. 加入診斷紀錄，顯示每次補位的 `current_table_bb`、raw／actual entry BB 與盲注級別。
4. 不加入 PR #86 的玩家領先加速盲注。
5. 先跑瀏覽器測試與人工完整通關，再考慮正式合併。
