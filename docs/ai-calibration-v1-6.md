# AI 難度校準實驗室 V1.6

## 目的

V1.6 不新增角色招式，也不直接調整 AI 參數。它先建立可重現的量化基準，避免只憑體感判斷 AI 是否變強、變弱或變得過度侵略。

校準器只在測試時載入：

```text
tests/support/ai-calibration-lab-v1.js
```

正式網站不會載入此檔案，不增加玩家端下載量，也不修改實際牌局狀態。

## 翻牌前矩陣

針對 10 位中階與高階角色，測量完整 169 種起手牌類別，並依實際組合數加權：

- 口袋對：每類 6 種組合
- 同花非對子：每類 4 種組合
- 不同花非對子：每類 12 種組合
- 全部合計：1,326 種兩張牌組合

測量情境：

- UTG、CO、BTN、SB 無人開池
- BTN 面對一次公開開池
- BTN 面對公開 3-bet
- BTN 面對開池加一位跟注者的 Squeeze 情境

輸出指標：

- 位置開池率與 VPIP
- 平均開池尺寸
- 面對開池的 Fold／Call／3-bet
- 面對 3-bet 的 Fold／Continue／4-bet
- 頂端範圍繼續率
- Squeeze 率
- 角色頻率指紋

## 翻牌後固定情境

每位角色以固定種子重複執行：

- 單挑乾燥翻牌空氣牌
- 單挑強聽牌
- 河牌薄價值
- 河牌 Bluff Catch
- 多人河牌空氣牌
- 多人河牌強價值

輸出：

- 空氣牌侵略率
- 強聽牌侵略率
- 薄價值下注率
- Bluff Catch 繼續率
- 多人空氣牌侵略率
- 多人強價值下注率
- 各類下注平均尺寸

## 固定種子

所有需要亂數的決策都使用可重現的種子。相同程式、相同種子與相同輸入，序列化後的完整報表必須完全一致。

預設種子：

```text
1604
```

## 執行方式

只執行 Chromium 校準：

```bash
npm run test:ai-calibration
```

完整瀏覽器回歸仍使用：

```bash
npm run test:e2e
```

Playwright 報表會附加：

```text
ai-calibration-v1-6.json
ai-calibration-v1-6.md
```

## 驗收原則

V1.6 先檢查結構與相對差異，不把目前數字宣稱為 GTO 或真實 solver 解答：

- BTN 開池率不得低於 UTG
- 侵略角色群的 BTN 開池與 3-bet 平均值應高於保守角色群
- 頂端範圍面對 3-bet 應維持高繼續率
- 多人空氣牌侵略率不得高於單挑空氣牌侵略率
- 多人強價值侵略率不得低於多人空氣牌侵略率
- 10 位角色至少形成 6 種不同翻牌前頻率指紋
- Oracle、Chronos、Gemini 不由此校準器接管

## 公平資訊邊界

校準器與被測 AI 都不得讀取：

- 對手隱藏底牌
- 真實牌堆順序
- 未來公共牌
- 預定勝負答案

公平性探針會把對手 `cards` 設為一讀取就拋錯的 getter；校準仍必須正常完成。

## 後續用途

當報表顯示角色過度緊、過度鬆、詐唬異常或角色頻率過度接近時，再建立獨立的小型調整 PR。V1.6 本身不為了通過校準而改動正式 AI 策略。
