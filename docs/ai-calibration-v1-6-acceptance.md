# V1.6 AI 校準驗收清單

- 校準器只在測試時注入，不由正式首頁載入
- 完整產生 169 種起手牌類別與 1,326 種組合權重
- 10 位中階與高階角色都有獨立報表
- 輸出 UTG／CO／BTN／SB 開池率與 VPIP
- 輸出面對開池的 Fold／Call／3-bet
- 輸出面對 3-bet 的 Fold／Continue／4-bet
- 輸出 Squeeze 與頂端範圍繼續率
- 輸出單挑空氣牌、強聽牌、薄價值與 Bluff Catch 指標
- 輸出多人空氣牌與多人強價值指標
- 相同種子與輸入產生完全相同 JSON
- Playwright 報表附加 JSON 與 Markdown 校準報表
- BTN 開池率不低於 UTG
- 侵略角色群的平均 BTN 開池與 3-bet 高於保守角色群
- 多人空氣牌侵略不高於單挑空氣牌
- 多人強價值侵略不低於多人空氣牌
- 至少形成 6 種角色頻率指紋
- 對手底牌 getter 拋錯時校準仍可完成
- 報表不包含 deck、opponentCards 或 futureBoard
- Oracle、Chronos、Gemini 不在 V1.6 支援清單
- Static、Chromium、WebKit 全部通過後才可合併
