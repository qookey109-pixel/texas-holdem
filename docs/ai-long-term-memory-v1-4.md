# AI 長期玩家記憶 V1.4

## 目的

讓中階與高階 AI 的 V1.3 公開玩家模型在重新整理後仍能延續；登入淘汰賽時，也能透過既有雲端存檔跨裝置恢復。

## 保存內容

只保存聚合計數：

- 各街公開 Fold / Call / Check / Raise / All-in 次數
- 面對公開壓力的 Fold / Call / Raise 次數
- Check-Fold / Check-Call / Check-Raise 次數
- 公開下注尺寸分布
- 公開位置的開池、3-bet、4-bet 與 Limp 次數
- 已觀察手數與公開行動數

## 不保存內容

- 玩家或對手底牌
- 公共牌內容
- 真實牌堆順序
- 未來公共牌
- 單次行動逐步歷史
- 對手私人資料
- 預定勝負答案

## 儲存層

- 未登入：瀏覽器本機安全快照
- 已登入：依帳號分離的本機快照
- 淘汰賽已有雲端存檔：將安全快照加入同一份 JSON payload

主淘汰賽模組仍可忽略額外欄位並正常載入舊 V1 / V2 存檔。V1.4 橋接層獨立讀寫 `aiPlayerModel` 欄位，不修改底牌與牌局進度存檔格式。

## 安全處理

所有本機與雲端資料載入前都會：

- 只接受白名單欄位
- 將數值轉成非負整數
- 限制最大樣本數
- 限制位置鍵格式與數量
- 修正不可能的子計數
- 移除逐步行動、牌張與未知欄位

## 合併規則

跨裝置或本機／雲端同時存在時，各聚合計數採較大值，不直接相加，避免同一批樣本重複計算。樣本不足時，V1.3 仍沿用平滑先驗與最低門檻。
